1. OpenStreetMap Export

URL: https://www.openstreetmap.org/export

License: ODbL 1.0 | Commercial: ✅ YES

Interactive map export of geographic data. Excellent coverage in Tamil Nadu urban areas. Free daily updates with millions of contributors.

Data Types: Buildings, roads, amenities, administrative boundaries

Attribution: © OpenStreetMap contributors

✅ Fully Operational

2. Overpass API

URL: https://overpass-api.de/api/interpreter

Query Language: Overpass QL | Commercial: ✅ YES

Programmatic query service for OpenStreetMap. Query specific features (hospitals, schools, roads) with structured syntax.

Rate Limit: No explicit limit; ~1 req/sec recommended

Response Formats: JSON, GeoJSON, XML

curl -X POST "https://overpass-api.de/api/interpreter" \
  -d '[bbox:8.0,76.5,13.5,80.5];
       (node["amenity"="hospital"];);
       out geojson;'
✅ Fully Operational
